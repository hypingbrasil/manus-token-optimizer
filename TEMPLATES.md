# Templates de Prompt Eficientes 📋

Copie e adapte estes modelos para economizar tokens.

## 1. Pesquisa e Resumo
**Objetivo**: Extrair informações de um site sem ler o conteúdo irrelevante.
```markdown
Acesse [URL]. Extraia apenas os pontos principais sobre [TEMA]. 
Saída: Lista em bullet points. 
Restrição: Sem introdução ou conclusão.
```

## 2. Geração de Código
**Objetivo**: Evitar explicações longas sobre como o código funciona.
```markdown
Linguagem: [LINGUAGEM]
Tarefa: [DESCREVA A TAREFA]
Saída: Apenas o código puro. Comentários apenas se necessário para lógica complexa.
```

## 3. Análise de Dados
**Objetivo**: Obter insights diretos.
```markdown
Dados: [COLE OS DADOS AQUI]
Tarefa: Identifique as 3 tendências principais.
Formato: Tabela (Tendência | Impacto | Recomendação).
```

## 4. Escrita de Artigos (Abordagem Modular)
**Objetivo**: Evitar que a IA gere texto genérico em documentos longos.
```markdown
Tema: [TEMA]
Ação: Crie apenas o esboço (outline) com 5 tópicos.
```
*(Após a resposta, peça cada tópico individualmente)*

## 5. Tradução e Revisão
```markdown
Tarefa: Traduza para [IDIOMA] ou Revise a gramática.
Texto: "[TEXTO]"
Saída: Apenas o texto resultante.
```
